# Crust & Q — Mobile Application Design System & Figma Workspace

## 1. Project Overview

- **Project Name**: Crust & Q
- **Platform**: Cross-Platform Mobile (iOS + Android canonical viewport: 390 × 844 pt)
- **Current Lifecycle State**: `AWAITING_USER_REVIEW`
- **Objective**: Complete mobile ordering and delivery application for an artisanal wood-fired pizza and slow-smoked craft BBQ restaurant chain in the United States, supporting both Customer ordering and Delivery Partner operational workflows.
