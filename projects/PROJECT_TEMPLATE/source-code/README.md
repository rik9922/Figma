# Project Source Code

## Workspace & Repository Strategy
In accordance with **Rule 8 (Code Implementation Workflow)**:
- Reusable design tooling and multi-project coordination live in the root `Figma/` repository.
- If this application has its own dedicated GitHub repository, configure its remote URL in `project.config.json` under `development.externalRepoUrl`.
- Alternatively, standalone companion components or prototypes can reside in this directory.
