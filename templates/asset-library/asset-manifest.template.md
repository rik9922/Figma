# Project Asset Manifest Template

This manifest tracks all visual assets generated, reviewed, approved, and imported into Figma.

## Approval Workflow Statuses
- `PENDING_REVIEW`: Asset generated and awaiting user review.
- `APPROVED`: User explicitly approved asset for design use and Figma import.
- `REJECTED`: User declined asset; stored in `assets/rejected/`.
- `IMPORTED_TO_FIGMA`: Asset verified on Figma canvas in target frame.
- `REQUIRES_REVISION`: Needs styling or parameter modifications.
- `LICENSE_BLOCKED`: Asset cannot be used commercially or pending licensing clearance.

## Commercial License Statuses
- `VERIFIED_COMMERCIAL_USE`: Explicitly permitted for commercial use per provider terms.
- `VERIFIED_NONCOMMERCIAL_ONLY`: Restricted to personal or evaluation use only.
- `RESTRICTED`: Specific trademark or dataset restrictions apply.
- `UNKNOWN`: Licensing not established.
- `PENDING_VERIFICATION`: Under review; **must NOT be treated as commercially approved**.
